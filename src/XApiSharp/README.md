# XApiSharp

Independent, community-maintained C#/.NET SDK for the public [X API v2](https://docs.x.com/x-api).

**Status:** early scaffolding (stage E0/E1). No endpoints are implemented yet. This package is not
installable from NuGet.org until a `1.0.0` release ships — see the repository root README for the
current status and roadmap.

This project is not affiliated with, endorsed by, or sponsored by X Corp.
