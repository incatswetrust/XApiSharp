# XApiSharp

Independent, community-maintained C#/.NET SDK for the public [X API v2](https://docs.x.com/x-api).

**Status:** pre-release. All 190 in-scope X API v2 operations are implemented and contract-tested;
live validation against the real API is still pending (blocked on paid API access - see the
repository root README). This package is not yet published to NuGet.org until a `1.0.0` release
ships — see the repository root README for the current status and roadmap.

This project is not affiliated with, endorsed by, or sponsored by X Corp.
